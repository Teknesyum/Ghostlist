## Amaç
Üç ürünleştirme parçası: betiklenebilir bir CLI (IT yöneticisi kitlesi + kendi entegrasyon
testimiz), toplu işlem öncesi sistem geri yükleme noktası (güven), ve derleme/test/yayın
otomasyonu. Kod imzalama **bu turda yok**; SHA256 yayımlanır.

## Kabul kriteri
1. **`Ghostlist.Cli`** ayrı konsol projesi, `Ghostlist.Core`'a bağlı, WPF'e **bağlı değil**.
   Komutlar:
   - `ghostlist scan [--category <ad>] [--json] [--min-confidence <n>]`
   - `ghostlist fix --id <bulgu-id> [--dry-run]`
   - `ghostlist fix --all [--min-confidence 90] [--dry-run]`
   - `ghostlist restore --list` / `ghostlist restore --backup <yol>`
   `--dry-run` hiçbir şey değiştirmez, ne yapacağını yazar. Çıkış kodları: 0 temiz,
   1 bulgu var, 2 hata. `--json` çıktısı satır satır ayrıştırılabilir olsun.
2. **Onaysız yıkım yok.** CLI'da `--all` varsayılan olarak onay ister; `--yes` ile geçilir.
   `--yes` olmadan boru hattında çalışmaz — bilinçli.
3. **Sistem geri yükleme noktası.** `SystemRestore.TryCreate(string description)`:
   yönetici varsa ve System Restore açıksa nokta oluşturur, aksi halde `false` döner ve
   **işlemi engellemez**. Toplu düzeltmeden önce çağrılır (GUI ve CLI). Windows'un 24 saatlik
   sıklık limitine takılırsa bu bir hata değil, sessiz `false`.
4. **CI.** `.github/workflows/ci.yml`: `windows-latest`, PR ve main push'ta
   `dotnet build` + `dotnet test -c Release`.
   `.github/workflows/release.yml`: `v*` tag'inde self-contained single-file `win-x64`
   publish, zip, SHA256 dosyası, GitHub Release'e ekli. İmzalama adımı yok.
5. `Ghostlist.sln` yeni CLI projesini içerir. Tüm projeler derleniyor, `dotnet test` yeşil.
6. CLI komut ayrıştırma testli (argüman → plan eşlemesi). Gerçek registry'ye yazan test yok.

## Arayüzler
T3/T4'ten: `IIssueProvider`, `Finding`, `Evidence`, `FixResult`, `CleanupService`, `IBackupSink`.
CLI **kendi kopyasını yazmaz** — GUI ile aynı `CleanupService` üzerinden çalışır.
CLI metinleri İngilizce; T5'in çeviri tablosuna bağlanma, CLI ayrı ve İngilizce kalır.

## Bağlam
- Yedek kökü: T1'in `BackupPaths` yardımcısı. Ayarlar `%LOCALAPPDATA%\Ghostlist\settings.json`
  (T5 yazıyor) — CLI ayar dosyasına **yazmasın**, gerekiyorsa okusun.
- Sistem geri yükleme için `SRSetRestorePoint` P/Invoke ya da WMI `SystemRestore` sınıfı;
  hangisini seçersen seç, hata yolu sessiz `false` olsun. İstisna sızdırma.
- Depo `github.com/Teknesyum/Ghostlist`; workflow'larda eski `ProgramFixer` adını kullanma.
- `scripts/install.ps1` release asset adına bağımlı — T1 onu güncelledi, release.yml'in
  ürettiği zip adı onunla **uyuşmalı**. Uyuşmazlık kurulumu kırar, kontrol et.
