## Amaç
Üç kapanış işi: ürünün yeni sürümden haberi olsun, dağıtımın `irm | iex` dışında saygın
bir yolu olsun, ve arayüz katmanının testi olsun (bugün 153 testin hepsi Core'da —
ViewModel'ler hiç test edilmiyor).

## Kabul kriteri
1. **Güncelleme kontrolü.** GitHub Releases API'sinden en son sürüm etiketi okunur,
   mevcut sürümle karşılaştırılır. Yeni sürüm varsa arayüzde **sessiz bir bildirim şeridi**
   + sürüm notlarına bağlantı. İndirme ve kurma **yok**.
2. **Kontrol kullanıcının denetiminde.** Açılışta otomatik kontrol **varsayılan olarak
   kapalı**; ayarlardan açılır, ayrıca elle "Güncellemeleri denetle" düğmesi var.
   Kapalıyken hiçbir ağ çağrısı yapılmaz — bunu testle sabitle.
3. **Ağ hatası sessiz.** Zaman aşımı (5 sn), 403 (API limiti), çevrimdışı — hiçbiri hata
   diyaloğu açmaz, uygulamayı yavaşlatmaz, taramayı engellemez. Elle kontrolde sonuç
   gösterilir, otomatik kontrolde sessizce geçilir.
4. **winget manifest.** `packaging/winget/` altında üç dosyalı manifest
   (`.installer.yaml`, `.locale.en-US.yaml`, `.yaml`), `Teknesyum.Ghostlist` kimliğiyle,
   sürüm ve SHA256 alanları `Directory.Build.props` ve release çıktısıyla uyumlu.
   **Manifest'i winget deposuna gönderme** — dosyalar depoda hazır dursun, gönderim
   kullanıcının kararı. README'ye winget kurulum satırı eklenir, "yayına alındığında"
   notuyla.
5. **ViewModel testleri.** En az şunlar: dil geçişi `tr`↔`en` anahtarları çözüyor mu;
   kategori gruplaması doğru sayıyor mu; toplu düzeltme seçimi artık klasör ve MSIX'i
   gerçekten dışarıda bırakıyor mu; güven eşiği altındaki bulgu düzeltilebilir görünmüyor mu.
   Bu dördü ürünün güvenlik vaadinin arayüz tarafı — testsiz kalmamalı.
6. **Dil dosyası bütünlüğü testi.** `tr.json` ve `en.json` anahtar kümeleri birebir aynı;
   biri eksikse test **kırmızı** olur. Bugün bu elle kontrol ediliyor.
7. `dotnet build -c Release` yeşil, tüm testler yeşil.

## Bağlam
- T8 `Directory.Build.props` ile sürümü tek yere aldı; güncelleme kontrolü ve winget
  manifest sürümü **oradan** okumalı, sabit yazmamalı.
- Sürüm karşılaştırması `v` önekli etiketlerle çalışır (`v2.0.0`); `SemanticVersion`
  benzeri bir karşılaştırma yaz, dize karşılaştırması yapma (`v2.0.10` < `v2.0.9` tuzağı).
- GitHub API kimliksiz saatte 60 istek verir; bu yüzden otomatik kontrol günde bir kezden
  fazla çalışmasın, son kontrol zamanı `settings.json`'a yazılsın.
- ViewModel testleri için WPF `Dispatcher` bağımlılığı sorun çıkarabilir; ViewModel'ler
  T5'te `ObservableObject` üstüne kuruldu, UI thread'i gerektirmeyen yollarını test et.
  Gerektiriyorsa testi zorlamak yerine ViewModel'i test edilebilir hale getir.
- README `yan_etki`: yalnızca winget satırı ekle, yeniden yazma.
