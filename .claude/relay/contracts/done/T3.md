## Amaç
İki iş: (a) ikili "Bozuk / Sağlam" damgasını **kanıt tabanlı** bir modele çevirmek,
(b) bugün pes edilen iki büyük kategoriyi kazanmak — MSI yetimleri ve MSIX/UWP paketleri.
Ayrıca T4'ün üstüne bineceği `IIssueProvider` soyutlamasını burada açmak.

## Kabul kriteri
1. **Kanıt modeli.** `Finding` başına kanıt listesi (`Evidence(Kind, Detail, Weight)`).
   Örnek kanıtlar: uninstaller dosyası yok · `InstallLocation` klasörü yok · `DisplayIcon`
   hedefi yok · MSI ürün kaydı yok · MSI cache paketi yok. Sonuç `Confidence` (0-100) ve
   `EntryStatus`. Eşikler tek yerde sabit olarak dursun, koda serpilmesin.
2. **Silme eşiği katı kalır.** Otomatik düzeltme yalnızca `Confidence >= 90` **ve** en az
   iki bağımsız kanıt varken önerilir. Tek kanıtla `Broken` damgası basılmaz.
3. **MSI yetimleri.** `msiexec` görünce artık pes edilmez. ProductCode (T2'nin
   `ResolveMsiProductCode`'u) ile: `HKLM\SOFTWARE\Classes\Installer\Products\<packed>` kaydı
   ve `%WINDIR%\Installer\<…>.msi` cache paketi aranır. İkisi de yoksa yetim MSI kaydıdır.
   Packed GUID dönüşümü (ProductCode ↔ 32 haneli sıkıştırılmış biçim) testli olsun.
4. **MSIX/UWP.** Ayrı sağlayıcı: staged olup manifesti veya kurulum klasörü kayıp paketler.
   Registry silme **yapma** — bu kategoride önerilen eylem `Remove-AppxPackage` komutunun
   kullanıcıya gösterilmesi. Otomatik çalıştırma yok.
5. **`IIssueProvider`.** `string Id`, `string Category`, `IReadOnlyList<Finding> Scan()`,
   `FixResult Fix(Finding, IBackupSink)`. Mevcut uninstall taraması bu arayüzü uygulayan
   `UninstallEntryProvider`'a taşınır. `CleanupService` sağlayıcı listesi üzerinden çalışır,
   tek tipe bağlı kalmaz.
6. Sistem bileşeni ve çözülemeyen komut korumaları aynen durur — gevşetme.
7. Testler: kanıt→skor eşlemesi, packed GUID, MSI yetim kararı, MSIX kararı. `dotnet test` yeşil.

## Çıktı
**T4/T5/T6'nın dayanacağı gerçek imzalar:**
```csharp
public sealed record Evidence(string Kind, string Detail, int Weight);   // IsConclusive => Weight > 0
public sealed record Finding(string Id, string Title, string? Subtitle, EntryStatus Status,
    int Confidence, IReadOnlyList<Evidence> Evidence, string ProviderId, object Payload);  // IsSelected mutable
public sealed record FixResult(bool Success, string ResultKey, string? BackupPath = null, string? ManualCommand = null);
public interface IIssueProvider { string Id { get; } string Category { get; }
    IReadOnlyList<Finding> Scan(); FixResult Fix(Finding finding, IBackupSink backup); }
public interface IBackupSink {
    string SaveRegistryTree(RegistryTreeBackup backup, string label);
    string MoveFileToBackup(string sourcePath, string label);
    string SaveText(string content, string label, string extension);
    void Restore(string backupPath);
    IReadOnlyList<string> List(); }
public interface IFileSystem {
    ProbeResult ProbeFile(string path);                   // Present / Missing / Unknown
    ProbeResult ProbeDirectory(string path);
    IReadOnlyList<string>? TryListEntries(string path);   // null = okunamadı
    DateTimeOffset? TryGetLastWrite(string path); }
public sealed class CleanupService(IReadOnlyList<IIssueProvider> providers, IBackupSink backup) {
    IReadOnlyList<Finding> Scan(); string CategoryOf(Finding); bool IsAutoFixable(Finding);
    IReadOnlyList<Finding> AutoFixable(IEnumerable<Finding>); FixResult Fix(Finding);
    IReadOnlyList<string> ListBackups(); void Restore(string);
    static CleanupService CreateDefault(string backupDirectory); }
```
- **`IFileSystem` artık üç durumlu.** `bool FileExists` gitti. "Erişilemeyen yer yok sayılmaz"
  kuralı tip seviyesinde: `ProbeResult.Unknown` ya kanıt üretmez ya da `Weight = 0`
  ("belirsiz") kanıt üretir; belirsiz kanıt varsa `Evaluate` güveni `UncertainCeiling = 60`'a
  çakar → `Broken` imkânsız hale gelir.
- **Skorlama tek yerde:** `ConfidenceRules.Evaluate(evidence, ceiling = 100)`. Ağırlıklar
  `EvidenceWeights`, anahtarlar `EvidenceKinds`, kategoriler `Categories`. T4 kendi sabitini
  eklemesin, bu üç sınıfa yazsın. Artık klasör için `LeftoverFolderCeiling = 80` hazır —
  `Evaluate(evidence, ConfidenceRules.LeftoverFolderCeiling)` çağır, tavan kendiliğinden
  otomatik eşiğin (90) altında kalır.
- **Broken kuralı:** en az 2 *sonuçlandırıcı* kanıt **ve** toplam >= 70. Tek kanıt ne kadar ağır
  olursa olsun `Suspicious`. Otomatik düzeltme ayrıca kategori kapısından geçer:
  `AutoFixableCategories = [uninstall, shortcut, startup, task]` — `folder` ve `msix` yok.
- **Bağımsızlık gerçekten korunuyor:** `DisplayIcon` hedefi kaldırıcıyla aynıysa,
  `InstallLocation` hedefin klasörüyle aynıysa ikinci kanıt sayılmaz (testi var).
- **MSI:** `Installer\Products\<packed>` (HKLM Classes + HKCU) ve
  `Installer\UserData\<SID>\Products\<packed>\InstallProperties` iki bağımsız kayıt olarak
  sorgulanır; ikisi de yoksa 45+45=90 → yetim. Cache paketi **yalnızca `LocalPackage` yolu
  kayıtlıysa** yargılanır, yoksa hiç kanıt üretilmez. `UserData` kökü açılamıyorsa `Unknown`.
  `PackedGuid.Pack/Unpack` testli (round-trip + sabit vektör).
- **MSIX:** `AppxProvider`, `PackageRepository\Packages` altındaki staged paketleri okur.
  Registry'ye **hiç yazmaz**; `Fix` daima `FixResult.Manual("Remove-AppxPackage -Package <ad>")`
  döner ve `IBackupSink`'e dokunmaz (testle sabitlendi). Mağaza kökü okunamıyorsa `Suspicious`.
- **`ProviderId == Category`** bugünkü iki sağlayıcıda aynı dize. T5 gruplarken
  `CleanupService.CategoryOf(finding)` kullansın, `ProviderId`'ye doğrudan bakmasın.
- **`UninstallEntryProvider.Scan()` her kaydı döndürür** (Healthy dahil) — mevcut arayüz tüm
  yüklü uygulamaları listeliyor, bu davranış korundu. Diğer sağlayıcılar yalnız bulgu döndürsün.
- Core'da kullanıcı metni kalmadı: `UninstallEntry.Status/Reason/StatusText/IsSelected` silindi,
  `EntryStatus` + `EvidenceKinds` + `FixResultKeys` dil-bağımsız anahtar. Tek istisna Core'da
  kalan birkaç `InvalidOperationException` mesajı (Türkçe); T5 isterse sarar.
